# Trustworthy ML & NLP for Online Misinformation Detection

## Overview

This project explores the use of machine learning and natural language processing to detect online misinformation while also focusing on model reliability, explainability, and limitations.

The project is being developed as part of my M.S. Data Science capstone at Lewis University.

## Objectives

- Preprocess and analyze news-text datasets
- Build machine learning models for misinformation classification
- Evaluate model performance using appropriate metrics
- Investigate model explainability and reliability
- Analyze model errors and limitations
- Develop a web-based interface for predictions

## Technologies

- Python
- Pandas
- NumPy
- Scikit-learn
- Natural Language Processing
- Matplotlib
- Jupyter Notebook
- Django

## Planned Workflow

1. Data collection and preprocessing
2. Exploratory data analysis
3. Text preprocessing and feature engineering
4. Model training
5. Model evaluation
6. Explainability and error analysis
7. Web deployment
