    How a result is decided

    DistilBERT V1 classifies statement text into six LIAR labels. Softmax is applied to logits divided by the validation-fitted temperature (1.429502). Predictions with maximum calibrated probability below 0.275 are withheld.

    Normalized entropy and the gap between the two largest probabilities describe uncertainty. The threshold is experimental, not a guarantee of correctness.

    Held-out LIAR test accuracy: 29.04%; selective accuracy: 31.09% at 59.91% coverage. No external evidence is retrieved. SHAP and LIME explain the candidate class on demand, not factual evidence.

    Project overview

    Trustworthy Misinformation Detection: Evaluating Explainability, Calibration, and Cross-Domain Generalization of NLP Models

    Authors: Sabin Adhikari and Mohammad Hasan Ali Alshaggah. CPSC 59000, Lewis University, Fall 2026.
    Code: github.com/adhisabin19/trustworthy-misinformation-detection

    The project asks whether misinformation classifiers are not only accurate but also explainable, well calibrated, and robust when the topic or domain changes. It extends a 2023 undergraduate fake news detection portal into a reproducible comparison of classical and transformer models. This web app is the user-facing part: it provides a text classifier with calibrated confidence and abstention. Independent evidence retrieval is not implemented.

    The numbers on this page were checked against the result files in the GitHub repository (CSV and JSON). The class-weighted DistilBERT and Week 3 pilot scores come from the Week 4 notebook.

    Pilot: project model vs ChatGPT and Claude

    On 60 balanced validation statements, closed-book (no web access): class-weighted DistilBERT 21/60, Claude 19/60, ChatGPT 18/60.

    Sixty statements is too few to rank the three. Model versions still need to be documented. These counts are from the Week 4 report.

    Limitations

    Text-only models cannot check facts, so fine label differences are hard. Results so far are validation-only. Calibration, topic shift and cross-domain tests are not done yet. The URL checker’s point weights are a proposal that still needs validation on labeled examples.
